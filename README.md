after cloning of this repo do these steps given below :-

inside the terminal type :- npm install , npm install bcrypt node-cron and npm install form-data

create one uploads folder in the directory

make sure to enter your keys and uri in the .env file (change the .env.example to .env)

upload the esp32cam c++ code in your esp32cam using arduino or anyother software of your choice (make sure to remove the comments from the code , make sure to add your wifi credentials i.e name and password in the code and after pasting the code make sure to either comment out the code in vs code or delete the file )
also enter the ip address of the server in the c++ code 

to run the server type node server.js

to connect with the server and talk with ai here is the app to download or check release(you can also use web dashboard by opening the test.html file in browser) :-

https://github.com/Soham-Coder-OG/Recall_Cast/releases/tag/Recall_Cast_Android_App

after downloading and opening the app , press and hold the recallcast top branding for 5 sec then enter the password (contact me for the password) then enter the the ip address of your laptop there and you are all set to go.
